# Security policy

The supported version is the current default branch and the live GitHub Pages
site built from it.

Report a suspected security vulnerability privately through the repository's
[GitHub Security Advisories](https://github.com/rkalani1/ML/security/advisories/new).
Include the affected URL or file, impact, and minimal reproduction steps.
Please do not open a public issue for an unpatched vulnerability.

Do not include patient information, credentials, private keys, access tokens,
or other confidential material in any report. This static educational site is
not an appropriate place to submit clinical cases. For an ordinary factual,
accessibility, or rights concern that is safe to discuss publicly, use the
[issue tracker](https://github.com/rkalani1/ML/issues).

No response time or bounty is promised. Reports will be assessed in good faith,
and verified issues will be corrected or the affected material will be removed
as appropriate.
